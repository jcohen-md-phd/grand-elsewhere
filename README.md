# The Grand Elsewhere — Passenger Website

A static, GitHub Pages–ready website for the Mothership one-shot.

## Pages
- `index.html` — Invitation / home
- `visual-deck.html` — Ship experiences and gallery
- `ship-map.html` — Interactive decks and searchable directory
- `grand_elsewhere_player_manifest.html` — Passenger and crew manifest

## Publish to GitHub Pages
1. Create a **public** GitHub repository, such as `grand-elsewhere`.
2. Upload all files from this ZIP **into the repository root**, not inside an extra folder.
3. Go to **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)` and Save.
4. Your site should become available at `https://YOUR-USERNAME.github.io/grand-elsewhere/`. It may take a few minutes.

## Notes
- No backend or accounts are required.
- Images are embedded into the two gallery/manifest HTML pages. This keeps deployment simple.
- The navigation and styling are shared through `site.css` and `site.js`.
- The original Mothership character creator is intentionally excluded; share printable character sheets separately.
- External Google Fonts may require an internet connection; system fallback fonts are included.
