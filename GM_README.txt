GRAND ELSEWHERE — GM PAGES

Upload these THREE files to the same folder as index.html in your GitHub Pages repository:
- gm-dash.html (GM landing page and autosaved session notes)
- grand_elsewhere_gm.html (NPC dossiers, with new links back to dashboard and location guide)
- gm-locations.html (location reference and per-location notes)

Visit: https://jcohen-md-phd.github.io/grand-elsewhere/gm-dash.html

There are no new links from the player-facing site. These are unlisted, not private: anyone who knows the URLs or browses your public GitHub repository can read the page source and GM secrets.

Notes and trackers persist in localStorage in the same browser, not in GitHub and not across devices. Use the Export controls on each page to keep backups. The location descriptions include creative suggestions; adjust canon as needed.
